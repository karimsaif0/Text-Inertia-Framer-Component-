## Controls

### Text
Set the words displayed by the component.

### Font
Choose the font family, style, and weight through Framer's native font control.

### Size
Adjust the text size from 8px to 300px.

### Tracking
Control letter spacing for tighter or more open typography.

### Line Height
Adjust the vertical rhythm of the text.

### Color
Choose the text color.

### Strength
Controls how far each word is pushed by cursor movement.

### Velocity
Controls how strongly cursor speed influences the interaction.

### Rotation
Controls the amount of word rotation during interaction.

### Elasticity
Controls how quickly words respond to and return from their target position.

### Align
Choose left, center, or right alignment.

### Disabled
Turn off cursor interaction while keeping the typography visible.

## Built for Framer

Karim Saif Text Inertia is designed as a native Framer Code Component with responsive layout support, static-renderer handling, reduced-motion support, and automatic animation cleanup.

## Usage

1. Add the component to a Framer project.
2. Set the text and typography controls.
3. Adjust Strength, Velocity, Rotation, and Elasticity to create the desired interaction.
4. Preview the component and move the cursor across individual words.
